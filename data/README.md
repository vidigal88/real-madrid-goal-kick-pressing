# Local Data Folder

This folder is intentionally kept empty in the public repository.

Place private raw and processed data here locally if you want to run the pipeline:

data/
├── raw/
│   └── RealMadrid/
│       ├── meta/
│       ├── dynamic/
│       └── tracking_parquet/
├── interim/
└── processed/

Do not commit real event/tracking data, processed parquet files, model artifacts derived from licensed data, or compressed data archives.
